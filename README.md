# 🧭 Math Adventure

เกมผจญภัยคณิตศาสตร์สำหรับนักเรียนชั้นประถมศึกษาปีที่ 4 – 6

แนวคิดหลักของเกม: **Explore → Quest → Math Challenge → Reward → Level Up → Unlock**

> สถานะปัจจุบัน: **Part 1 (ต้นแบบที่เล่นได้จริง)** — ข้อมูลทั้งหมดเก็บในเครื่องผู้เล่นด้วย `localStorage` ยังไม่ต่อ Backend

---

## เริ่มเล่น

ต้องมี Node.js เวอร์ชัน 18 ขึ้นไป

```bash
npm install
npm run dev
```

จากนั้นเปิดเบราว์เซอร์ไปที่ URL ที่แสดงบนหน้าจอ (ปกติคือ `http://localhost:5173`)

คำสั่งอื่น ๆ

```bash
npm run build      # ตรวจ TypeScript แล้ว build ไฟล์สำหรับขึ้นเซิร์ฟเวอร์จริง
npm run preview    # ลองเปิดไฟล์ที่ build แล้ว
npm run typecheck  # ตรวจ type อย่างเดียว
```

## เส้นทางการเล่นใน Part 1

```
เปิดเกม → สร้างตัวละคร (เลือกชื่อ + อาชีพ 1 ใน 6)
        → เมนูหลัก → แผนที่โลก → World 1 → เลือกด่าน
        → ตอบโจทย์คณิตศาสตร์ → ได้ EXP + เหรียญ → หน้ารางวัล
        → กลับแผนที่ (รีเฟรชแล้วข้อมูลยังอยู่)
```

## ระบบที่ทำงานจริงแล้ว

| ระบบ | รายละเอียด |
| --- | --- |
| ตัวละคร | ชื่อ + อาชีพ 6 แบบ, เริ่มที่ Lv.1 / 0 EXP / 100 เหรียญ / HP 100 |
| แผนที่โลก | 6 โลก โดย World 1 เปิดให้เล่น ส่วน World 2–6 ล็อกไว้ |
| ด่าน | World 1 มี 5 ด่าน ปลดล็อกไล่ตามลำดับ ด่านสุดท้ายเป็นมินิบอส |
| โจทย์ | คลังโจทย์ 28 ข้อ (บวก ลบ คูณ หาร) + ตัวสร้างโจทย์สำรองเมื่อคลังไม่พอ |
| รางวัล | ตอบถูก +10 EXP / +5 เหรียญ, จบด่านได้โบนัสตามที่กำหนดในแต่ละด่าน |
| เลเวล | Lv.1 ต้องการ 100 EXP, Lv.2 → 150, Lv.3 → 200 (เพิ่มขั้นละ 50) |
| บันทึกข้อมูล | `localStorage` พร้อมระบบตรวจสอบและซ่อมข้อมูลที่เสียหาย |
| ความสำเร็จ | 6 รายการ คำนวณจากข้อมูลผู้เล่นจริง |
| ตั้งค่า | เปิด/ปิดเสียง, ลดการเคลื่อนไหว, ลบข้อมูลเริ่มใหม่ |

## แนวทางการออกแบบสำหรับเด็ก

- ปุ่มหลักสูงอย่างน้อย 48–60px แตะง่ายบนมือถือ
- ใช้ภาษาไทยทั้งหมด ไม่ใช้ศัพท์เทคนิค
- ตอบผิดไม่เสียพลังชีวิต และให้ลองใหม่ได้เสมอ พร้อมคำใบ้
- บอกถูก/ผิดด้วย **สี + ไอคอน + ข้อความ** ไม่ใช้สีอย่างเดียว
- รองรับการใช้คีย์บอร์ด และมีกรอบโฟกัสที่มองเห็นชัด
- มีตัวเลือก "ลดการเคลื่อนไหว" และเคารพ `prefers-reduced-motion` ของระบบ

## โครงสร้างโปรเจกต์

```
src/
├── components/     # ส่วนประกอบ UI ที่ใช้ซ้ำ (ปุ่ม, แถบ EXP, การ์ดโลก, โจทย์ ฯลฯ)
├── pages/          # หน้าจอแต่ละหน้าของเกม
├── context/        # GameContext เก็บสถานะผู้เล่นและรางวัล
├── routes/         # ตัวคุ้มกันเส้นทางที่ต้องมีตัวละครก่อน
├── data/           # ข้อมูลเกม: โลก, ด่าน, โจทย์, อาชีพ, ความสำเร็จ
├── types/          # นิยาม TypeScript
├── services/       # storage.ts จัดการ localStorage
└── utils/          # ระบบเลเวล, ตัวสร้างโจทย์, การปลดล็อก, เสียง
```

หลักการที่ยึดไว้

- **ข้อมูลเกมอยู่ใน `data/` เท่านั้น** ไม่ hard-code ไว้ใน component
- **ตรรกะอยู่ใน `utils/` และ `services/`** component ทำหน้าที่แสดงผลเป็นหลัก
- TypeScript แบบ strict ไม่ใช้ `any`
