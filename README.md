# 🧭 Math Adventure

เกมผจญภัยคณิตศาสตร์สำหรับนักเรียนชั้นประถมศึกษาปีที่ 4 – 6

แนวคิดหลักของเกม: **Explore → Quest → Math Challenge → Reward → Level Up → Unlock**

> สถานะปัจจุบัน: **Part 3** — ระบบโลก ด่าน ภารกิจ และการปลดล็อก ข้อมูลทั้งหมดเก็บในเครื่องผู้เล่นด้วย `localStorage` ยังไม่ต่อ Backend

---

## เริ่มเล่น

ต้องมี Node.js เวอร์ชัน 18 ขึ้นไป

```bash
npm install
npm run dev
```

จากนั้นเปิดเบราว์เซอร์ไปที่ URL ที่แสดงบนหน้าจอ (ปกติคือ `http://localhost:5173`)

คำสั่งอื่น ๆ

```bash
npm run build      # ตรวจ TypeScript แล้ว build ไฟล์สำหรับขึ้นเซิร์ฟเวอร์จริง
npm run preview    # ลองเปิดไฟล์ที่ build แล้ว
npm run typecheck  # ตรวจ type อย่างเดียว
```

## เส้นทางการเล่น

```
เปิดเกม → สร้างตัวละคร (เลือกชื่อ + อาชีพ 1 ใน 6)
        → เมนูหลัก → แผนที่โลก → World 1 → แผนที่ด่าน
        → เลือกด่าน → NPC เล่าภารกิจ → ตอบโจทย์คณิตศาสตร์
        → หน้าผลลัพธ์: ดาว + รางวัล + ปลดล็อกด่านถัดไป
        → สะสมดาวจนพิชิตโลก → ปลดล็อกโลกใหม่
        → (รีเฟรชแล้วความคืบหน้าทั้งหมดยังอยู่)
```

### ห้องเรขาคณิต — เครื่องมือวาดรูปหลายเหลี่ยมสำหรับสอนหน้าชั้น

เปิดที่ `#/geometry` หรือกดจากเมนูหลัก และเป็นหน้าเดียวในเกมที่ **เข้าได้โดยไม่ต้องสร้างตัวละคร**
เพราะคุณครูมักเปิดค้างไว้บนจอหน้าห้องเพื่อสาธิต ไม่ได้เข้ามาเล่นเกม

ในกล่องเครื่องมือมี

- **วงเวียน** วางอยู่บนกระดาษตลอดเหมือนของจริง มีที่จับสามจุดที่ทำคนละอย่าง
  ลากเข็มเพื่อย้ายที่ปัก ลากปุ่ม ↔ บนขาดินสอเพื่อกางรัศมี และจับหัวหรือปลายดินสอหมุนเพื่อวาด
  **แตะกระดาษเฉย ๆ ไม่ทำให้เกิดเส้น** ระยะกางคงอยู่ตอนย้ายเข็ม จึงแบ่งเส้นรอบวงเป็นหกส่วนได้จริง
- **ครึ่งวงกลมวัดมุม** ลากย้ายและหมุนได้ มีขีดครบทุกองศาและเลขสองแถวเหมือนของจริง
  จิ้มบนแถบสเกลเพื่อยิงเส้นออกไปตามองศาที่ต้องการ (วิธีสร้างห้าเหลี่ยมด้านเท่าด้วยมุม 108°)
- **ไม้บรรทัด 20 ซม.** วางแล้วลากดินสอตามขอบ เส้นจะแนบขอบให้ตรงเป๊ะโดยไม่ต้องลากนิ้วให้ตรง
- **ดินสอ ยางลบ ปักจุด A B C เครื่องมือวัดมุมสามจุด และรูปหลายเหลี่ยมด้านเท่า 3–12 ด้าน**
- แม่เหล็กดูดเข้าจุดเดิม **จุดที่ส่วนโค้งตัดกัน** และเส้นตาราง ทำให้ปลายเส้นชนกันพอดี
  รูปจึงปิดสนิทและมุมที่คำนวณได้ไม่เพี้ยน ทุกเส้นมีจุดปลายให้เห็นว่าเส้นจบตรงไหน
- ป้ายความยาวด้านและมุมภายในที่ขึ้นสดตามรูป พร้อมแผงสรุป เช่น
  ผลรวมมุมภายในของห้าเหลี่ยมเท่ากับ 540° ตามสูตร (n−2)×180
- **รูปด้านเท่าจิ้มแล้วถามเลย** ว่าเอากี่ด้านและด้านละกี่เซนติเมตร พร้อมบอกล่วงหน้าว่า
  มุมภายในจะเป็นเท่าไรและรอบรูปยาวเท่าไร (จะกดค้างลากกะขนาดเองก็ยังได้)
- **สั่งสร้างรูปด้วยตัวเลข** เลือกแบบ (เส้น จัตุรัส ผืนผ้า รูปด้านเท่า วงกลม ส่วนโค้ง มุมตามองศา)
  แล้วพิมพ์ตัวเลขหรือเลื่อนแถบ จิ้มวางตรงไหนก็ได้ พร้อมเงาตัวอย่างตามปลายเคอร์เซอร์
  สำหรับโจทย์ที่ต้องการรูปขนาดแน่นอนเพื่อเอาไปคิดต่อ เช่น พื้นที่สี่เหลี่ยมกว้าง 3 ยาว 5 ซม.
- **บันทึกงานอัตโนมัติ** ปิดแท็บหรือรีเฟรชแล้วงานยังอยู่ พร้อมสี ธีม และสวิตช์ที่ตั้งไว้
  (เก็บในเครื่องนี้เท่านั้น · เครื่องที่เก็บข้อมูลไม่ได้จะมีป้ายเตือนให้บันทึกรูปเอง)
- **ป้ายพื้นที่และความยาวรอบรูป กดเปิดปิดได้** ปิดไว้ตั้งแต่แรกเพราะใช้เฉพาะบางบทเรียน
- **ลากจุดบนรูปทีละจุดได้ พร้อมแม่เหล็ก** แก้มุมที่เบี้ยวโดยไม่ต้องลบทั้งรูป
  และการลากทั้งรูปก็ดูดเข้าจุด โดยจับมุมไหนมุมนั้นเป็นตัววิ่งไปชนเป้า
- **แก้รูปที่วาดไปแล้วได้** ลากปุ่ม ⤢ เพื่อย่อขยาย ลากปุ่ม ↻ เพื่อหมุน (ทำรอบใจกลางรูป
  และไม่ทำให้มุมภายในเปลี่ยน) หรือใส่ตัวเลขตรง ๆ เช่น ความยาวเส้น มุมที่ทำกับแนวนอน
  รัศมี ด้านละกี่เซนติเมตร และ **ขนาดมุมที่ต้องการเป็นองศา**
- **อุปกรณ์ย่อขยายได้** ครึ่งวงกลมปรับรัศมี 3–8 ซม. (มุมไม่ขึ้นกับขนาด วัดได้ตรงกันทุกอัน)
  ไม้บรรทัดปรับความยาว 5–30 ซม. โดยยืดแล้วได้ขีดเพิ่ม ไม่ใช่ขีดห่างขึ้น มาตราส่วนจึงยังจริงเสมอ
- **ป้ายตัวเลขวางนอกรูปให้เอง และลากหลบได้เมื่อยังบังเส้น** ลากได้ไกลสุด 1.6 ซม.
  และมีเส้นประบอกว่าป้ายนั้นเป็นของด้านไหน เพื่อไม่ให้ตัวเลขหลุดจากเจ้าของ
- บัตรภารกิจ 6 ใบ ที่เป็นขั้นตอนสร้างรูปจริงจากหนังสือเรียน เช่น สามเหลี่ยมด้านเท่าด้วยวงเวียน
  หกเหลี่ยมจากวงกลมวงเดียว และมุมฉากโดยไม่ใช้ไม้ฉาก
- **ใช้ปากกาสไตลัสเขียนได้** พร้อมกันฝ่ามือที่วางบนจอ กันนิ้วที่สองแย่งเส้นที่กำลังลาก
  และรองรับด้านยางลบของปากกา
- **วงแหวนบอกตำแหน่งปลายดินสอ** แทนลูกศรของระบบ มองเห็นชัดบนจอโปรเจกเตอร์
  และเปลี่ยนเป็นสีชมพูเมื่อแม่เหล็กจับจุดสำคัญไว้แล้ว
- **ซูม 50–400%** ด้วยปุ่ม ล้อเมาส์ หนีบสองนิ้ว หรือ `Ctrl +/-` ทุกวิธีตรึงจุดที่เล็งอยู่ไว้กับที่
  มีเครื่องมือ ✋ เลื่อนกระดาษสำหรับตอนซูมเข้า และภาพที่บันทึกยังเป็นกระดาษทั้งแผ่นเสมอ
- **กล่องเครื่องมือที่จัดใหม่ให้ใช้ง่าย** เครื่องมือเป็นตารางสามช่องเห็นครบในสายตาเดียว
  มีปุ่มลัด `1`–`9` ตั้งค่าของเครื่องมือที่เลือกอยู่โผล่ใต้ตารางทันที
  ส่วนที่เหลือพับเก็บได้ และตัวช่วยบนกระดาษเป็นชิปเล็ก ๆ ที่ติดแล้วเป็นสีเขียว
- **ของน่ารักที่ยังมีหน้าที่** สติกเกอร์ไว้ทำเครื่องหมายจุดสำคัญ · หน้าตาการ์ตูนบนรูปปิด
  (เด็กจำ "สามเหลี่ยมหน้ายิ้ม" ได้ง่ายกว่าชื่อเต็ม) · ธีมกระดาษสี่แบบที่สีอ่อนพอให้เส้นดินสอเด่นกว่าเสมอ
  · ประกายตอนวาดเสร็จ · และน้องวงเวียนที่กะพริบตาและชมเป็นระยะตามจำนวนรูปที่วาดได้
- ปุ่มย้อนกลับ/ทำซ้ำ และบันทึกผลงานเป็นไฟล์ภาพ (อุปกรณ์ช่วยจะไม่ติดไปในภาพ)

ตั้งใจไม่มีปุ่ม "สร้างหกเหลี่ยมให้เลย" เป็นทางลัดหลัก เพราะสิ่งที่เด็กต้องได้จากคาบนี้
คือวิธีสร้างรูปขึ้นมา ไม่ใช่ตัวรูป ส่วนรูปด้านเท่าสำเร็จรูปยังมีไว้ให้ครูยกตัวอย่างเร็ว ๆ

### โดมสีเขียว — ภาคต่อ ฟาร์มและทรัพยากรในโดม

ต่อจาก Safe Zone Guardians เด็กเข้าโดมได้แล้ว หน้าที่เปลี่ยนเป็นการทำให้โดมอยู่รอด
และเปิดประตูรับคนที่ยังรออยู่ข้างนอกให้ได้มากที่สุด

สิ่งที่ต่างจากเกมฟาร์มทั่วไปคือ **เวลาไม่ได้เดินด้วยนาฬิกา แต่เดินด้วยการคำนวณ**
จบวันเมื่อไร เกมจะเปิด "สมุดบัญชีฟาร์ม" ให้กรอกสรุปของวันนั้น
และตัวเลขที่กรอกคือตัวเลขจริงของฟาร์ม ไม่ใช่โจทย์ที่แปะไว้เฉย ๆ

| แถวในสมุดบัญชี | ทักษะ | ตัวอย่าง |
| --- | --- | --- |
| เก็บเกี่ยว | การคูณ · พื้นที่ | แปลง 6 × 8 ช่อง เก็บได้กี่ต้น |
| อาหารสัตว์ | การหารและเศษ | อาหาร 100 กก. แพะกินตัวละ 7 กก. เลี้ยงได้กี่ตัว เหลือกี่ กก. |
| ทรัพยากรโดม | โจทย์สองขั้นตอน · จำนวนหลักหมื่นขึ้นไป | เช้ามี 90,000 ผลิต 8,000 ใช้ 12,600 เหลือเท่าไร |
| พยากรณ์ | การหาร | เหลือเท่านี้ ขาดวันละเท่านี้ อยู่ได้อีกกี่วัน |
| ร้อยละ (ป.6) | ร้อยละ | ถังเต็มร้อยละเท่าไร |
| ค่าเฉลี่ย (ป.5 ขึ้นไป) | ค่าเฉลี่ย | สัตว์ 6 ตัวให้ผลผลิต 12 ชิ้น เฉลี่ยตัวละกี่ชิ้น |
| แปรรูป | การคูณ · กำไรขาดทุน | มะเขือเทศ 24 ผลขายสดได้เท่าไร ทำซอส 6 ขวดได้เท่าไร ได้เพิ่มกี่บาท |

**โรงแปรรูปกับตลาด** — แถวแปรรูปคือบทเรียนที่ตรงกับหัวใจที่สุด มาจากการศึกษา Heartopia
ที่บลูเบอร์รี่ 4 ลูกขายแยกได้ 64 ทอง แต่ทำแยมขายได้ 170 ทอง เด็กที่คำนวณส่วนต่างเป็น
จะรวยกว่าเด็กที่ขายของสด **โดยเกมไม่ต้องบังคับให้ทำโจทย์**
ราคาผลผลิตสดขึ้นลงทุกวัน ส่วนของแปรรูปราคานิ่ง จึงเห็นเองว่าการแปรรูปลดความเสี่ยงด้วย

ตอบผิดแล้วเกมยังใช้ค่าที่ถูกเสมอ ฟาร์มไม่เสียหายจากการคิดผิด
สิ่งที่ได้จากการตอบถูกทุกช่องคือแรงเพิ่มในวันรุ่งขึ้น ซึ่งเป็นรางวัล ไม่ใช่การไม่ถูกลงโทษ

สมดุลของเกมปรับจากการจำลองการเล่นสี่สิบวัน ไม่ใช่จากการคำนวณบนกระดาษ
ตัวจำลองถูกเก็บไว้เป็นชุดทดสอบถาวรใน `tests/farm.test.mjs` เพื่อกันเศรษฐกิจตันโดยไม่มีใครรู้

**รหัสฟาร์ม** — ข้อมูลเก็บใน `localStorage` ซึ่งผูกกับเบราว์เซอร์บนเครื่องนั้น
ฟาร์มจึงมี "รหัสฟาร์ม" เป็นข้อความสั้น ๆ (ไม่เกิน 200 ตัวอักษร) ให้คัดลอกไปวางเครื่องอื่นได้
โดยไม่ต้องมีเซิร์ฟเวอร์และไม่ต้องล็อกอิน

### ผจญภัยเมืองแห่งเวลา — การ์ดเกมอ่านเวลา ป.2 (`#/time`)

โหมดเดียวในแอปที่ทำสำหรับ ป.2 เพราะเริ่มจากชุดการ์ดที่ครูพิมพ์เล่นบนโต๊ะ (`time-adventure.html`)
แล้วย้ายมาเล่นบนจอได้ด้วย การ์ด 40 ใบ กติกา และฮีโร่สี่ตัว
(อัศวินทิม นางฟ้าใบเตย พ่อมดโมโม่ มังกรน้อยฟูฟู) เป็นชุดเดียวกันทุกอย่าง

| กองการ์ด | ทักษะ | วิธีตอบบนจอ |
| --- | --- | --- |
| ⏰ อ่านเวลา | อ่านเวลาเต็มชั่วโมง ครึ่งชั่วโมง ทีละ 5 นาที · เขียนเวลาเป็นตัวเลข | แตะตัวเลือก · หมุนเข็มนาฬิกา |
| 🔍 หาเวลา | จับคู่หน้าปัดกับเวลา | แตะตัวเลือก |
| 🏠 ชีวิตประจำวัน | เวลากับกิจวัตร · ก่อน/หลัง | แตะตัวเลือก · แตะเรียงลำดับ |
| ⚔️ ท้าทาย | เปรียบเทียบ เรียงลำดับ โจทย์สถานการณ์ | แตะตัวเลือก · แตะเรียงลำดับ · หมุนเข็ม |

เล่น 1–4 คนผลัดกันบนเครื่องเดียว ตอบถูกได้เหรียญในเกมและเดินตามจำนวนดาว
ถึงประตูปราสาทแล้วตอบการ์ดท้าทายถูกคือชนะ หรือกดนับเหรียญเมื่อหมดคาบ
จบเกมแล้วผู้เล่นของเครื่องได้เหรียญจริงตามจำนวนข้อที่ทั้งวงตอบถูก (มีเพดาน)
และสถิติเข้าหอเกียรติยศกับถ้วยรางวัลสองใบ

ท้ายเกมมีตารางบอกว่าแต่ละคนทำกองไหนได้กี่ข้อ พร้อมการ์ดที่เคยตอบผิดและเฉลย
ให้ครูเรียกทั้งกลุ่มมาทบทวนด้วยกัน ผลของผู้เล่นคนที่ 1 (เจ้าของเครื่อง)
เข้าตัวชี้วัด "เวลา (ป.2)" ในแผงคุณครูด้วย ส่วนเกมที่เล่นค้างไว้ถูกเก็บในเครื่อง
กลับมาหน้านี้แล้วกด "เล่นต่อเกมเดิม" ได้

**โหมดฝึกอ่านนาฬิกา** — เล่นคนเดียว รอบละ 10 ข้อ สุ่มเวลาใหม่ทุกข้อ ไม่ซ้ำการ์ด 40 ใบ
เด็กที่เล่นเกมกระดานซ้ำจนจำการ์ดได้จึงยังต้องอ่านเข็มจริง มีสามระดับ
(ตรงชั่วโมง · ครึ่งชั่วโมง · ทีละ 5 นาทีรวมตอนบ่าย) และสามแบบ (อ่านหน้าปัด · หมุนเข็ม · เขียนเวลา)
ตัวเลือกผิดมาจากความผิดพลาดที่เด็กทำจริง เช่น อ่านเลขที่เข็มสั้นกำลังจะไปถึง
หรืออ่านเลขที่เข็มยาวชี้เป็นนาทีตรง ๆ ข้อที่ผิดวนกลับมาให้ลองใหม่ท้ายรอบ

ชุดทดสอบ `tests/timeAdventure.test.mjs` ตรวจว่าเฉลยทุกใบถูกจริง
เช่น นาฬิกาบนการ์ดตรงกับตัวเลือกที่เป็นเฉลย และไม่มีเวลาช่วงตี 1 ถึงตี 5 หลุดเข้ามา
เอกสารออกแบบอยู่ที่ `docs/card-game-time-adventure.md`

### ZOMBIE RESCUE — เกมการคูณ ป.2 (`#/zombie`)

"ภารกิจรอดชีวิต พิชิตไวรัสซอมบี้" เกมร่วมมือ 1–4 คนบนเครื่องเดียว วาดกระดานตามภาพที่ครูออกแบบ
ทีมผู้รอดชีวิตเดินจากบ้านหลบภัยผ่าน 5 เขตไปถึง Z-CURE CENTER และแต่ละเขตฝึกแม่สูตรคูณแม่เดียว

| เขต | แม่ | โจทย์ |
| --- | --- | --- |
| 🏠 บ้านหลบภัย | ×2 | คูณคือการบวกซ้ำ · ซอมบี้กี่ตัว ตัวละกี่พลัง |
| 🏪 ตลาดเสบียง | ×3 | การคูณกับสิ่งของ · ราคาของ |
| 🏫 โรงเรียนซอมบี้ | ×4 | นับซอมบี้เป็นกลุ่มและเป็นแถว · หา □ |
| 🧪 ห้องทดลองลับ | ×5 | ใช้การคูณทำภารกิจ · หา □ |
| 🏥 Z-CURE CENTER | รวม (×2 ×3 ×4 ×5 ×10) | ภารกิจของ ดร.ซอมโบ |

วงจรของเกม: สำรวจ → เจอซอมบี้ → แก้โจทย์คูณ → ได้ทรัพยากร → สร้างยา → รักษาผู้ติดเชื้อ
ผลคูณของข้อที่ตอบถูกคือ "พลังวัคซีน" ที่เข้าหลอดของทีม ตัวเลขที่เด็กคิดออกมาจึงมีความหมายในเกม
ตอบผิด "ซอมบี้เข้ามาใกล้แล้ว!" เสีย ❤️ 1 แต่ไม่มีใครตกรอบ หมดแรงแค่กลับไปจุดพักฟื้นล่าสุด
ช่องบนกระดานเป็นไปตามภาพ: ➕ ได้ยา/อุปกรณ์ · ⚙️ การ์ดพิเศษ · ⚠️ เจอซอมบี้ · 💧 พักฟื้น · 🛒 ตลาด (ใช้ 🥫 เสบียงซื้อ)
เมื่อหลอดพลังเต็ม คนที่ยืนหน้าประตูช่วย ดร.ซอมโบ ผสมยา Z-CURE ได้ ทั้งทีมชนะ

โจทย์สร้างจากแม่แบบของแต่ละเขต สุ่มตัวเลขใหม่ทุกครั้ง เด็กที่เล่นซ้ำจึงจำคำตอบไม่ได้
ข้อเขียนประโยคการคูณยอมรับการสลับที่ตัวคูณเสมอ (3 × 4 กับ 4 × 3 ถูกทั้งคู่) เพราะหนังสือแต่ละเล่มเรียงไม่เหมือนกัน
มีโหมด **ฝึกสูตรคูณ** คนเดียว รอบละ 10 ข้อ เลือกแม่ได้ ข้อที่ผิดวนกลับมาท้ายรอบ
ผลของคนที่ 1 ส่งให้แผงคุณครูในตัวชี้วัด "การคูณ (ป.2)" และท้ายเกมมีตารางว่าใครสะดุดแม่ไหน
**📒 สมุดวัคซีน** สะสมสติกเกอร์สูตรคูณ 50 ช่อง (แม่ 2 3 4 5 10 คูณ 1–10) ข้อไหนตอบถูก 2 ครั้งติดกัน ซอมบี้ช่องนั้นหายป่วย
ข้อที่ตอบผิดล่าสุดขึ้นเป็น "ข้อที่ยังพลาด" และกดฝึกเฉพาะข้อพวกนั้นได้ทันที สะสมครบ 25 และ 50 ช่องได้ถ้วยรางวัล
แต่ละช่องคือชาวเมืองคนละคน มีชื่อและหน้าตาไม่ซ้ำกัน รักษาแล้วซอมบี้จะกลายเป็นคนหน้าเดิม ชุดพิมพ์ใช้ชาวเมืองชุดเดียวกัน

ชุดทดสอบ `tests/zombieRescue.test.mjs` สุ่มโจทย์หลายหมื่นข้อตรวจว่าเฉลยถูกและข้อความไม่เผยคำตอบ
และจำลองเกมหลายร้อยเกมตรวจว่าทุกเกมจบได้ในเวลาพอดีคาบ
เอกสารออกแบบอยู่ที่ `docs/zombie-rescue.md`

**ชุดพิมพ์** `zombie-rescue.html` (33 แผ่น A4) เล่นเกมเดียวกันบนโต๊ะ: กระดานแนวนอน การ์ดโจทย์ 70 ใบ (เขตละ 12 และ ดร.ซอมโบ 10)
การ์ดเปล่าให้เด็กแต่งโจทย์เอง การ์ดพิเศษ 8 ใบ การ์ดอุปกรณ์ 26 ใบ แผ่นผู้เล่น สมุดพลังวัคซีน ตัวนับ ตัวเดิน สมุดวัคซีนกระดาษ (คนละแผ่น) และเฉลย
ข้อมูลทั้งหมดในชุดพิมพ์ (กระดาน ตัวละคร การ์ดโจทย์ ราคา เป้าหลอดพลัง) สร้างจากโค้ดเกมด้วย `scripts/zombie-kit-data.mjs`
และชุดทดสอบฟ้องทันทีถ้าชุดพิมพ์ไม่ตรงกับเกมบนเว็บ เมื่อแก้เกมแล้วให้สร้างใหม่ด้วย

```
npx tsc -p tsconfig.tests.json --outDir /tmp/logic
node scripts/zombie-kit-data.mjs /tmp/logic
```

`zombie-cure.html` (ZOMBIE CURE) คือแบบร่างแรกก่อนครูส่งแนวคิดใหม่ (การ์ดตามสีช่องและทางแยกปลอดภัย/ทางลัด)
เก็บไว้ให้ครูที่พิมพ์ไปแล้ว แต่ไม่ได้ปรับตามเกมปัจจุบัน (ดู `docs/card-game-zombie-cure.md`)

### Safe Zone Guardians — โหมดสามมิติ

เกมในเกมที่เล่าเรื่องภาวะโลกร้อน แบ่งเป็นสามช่วง คือสำรวจเขาวงกตสามมิติหาไอเทมยังชีพ
หยุดพักให้ห้องเรียนอภิปรายหน้าประตูโดม แล้วแก้โจทย์ทรัพยากรตามตัวชี้วัด
ป.4/7 (ประมาณค่า) · ป.4/8 (ตัวไม่ทราบค่า) · ป.4/11 (โจทย์สองขั้นตอน) · ป.4/12 (สร้างโจทย์เอง)

ฉากสามมิติเขียนขึ้นเองทั้งหมดบน `<canvas>` สองมิติ ไม่ได้ใช้ไลบรารีสามมิติใด ๆ

## แนวทางการออกแบบสำหรับเด็ก

- ปุ่มหลักสูงอย่างน้อย 48–60px แตะง่ายบนมือถือ
- ใช้ภาษาไทยทั้งหมด ไม่ใช้ศัพท์เทคนิค
- ตอบผิดเสียพลังชีวิตเล็กน้อยแล้วได้คืนตอนจบด่าน ลองใหม่ได้เสมอ พร้อมคำใบ้
- บอกถูก/ผิดด้วย **สี + ไอคอน + ข้อความ** ไม่ใช้สีอย่างเดียว
- รองรับการใช้คีย์บอร์ด และมีกรอบโฟกัสที่มองเห็นชัด
- มีตัวเลือกปิดเอฟเฟกต์การเคลื่อนไหว และเคารพ `prefers-reduced-motion` ของระบบ
- ทักษะที่ยังไม่เคยฝึกแสดง "ยังไม่มีข้อมูล" แทนดาว 0 ดวง และใช้ข้อความชวนฝึกต่อเสมอ

## โครงสร้างโปรเจกต์

```
src/
├── components/     # ส่วนประกอบ UI ที่ใช้ซ้ำ (ปุ่ม, แถบ EXP, การ์ดด่าน, ดาว, โจทย์ ฯลฯ)
├── pages/          # หน้าจอแต่ละหน้าของเกม
├── context/        # GameContext เชื่อมทุกระบบเข้าด้วยกัน
├── hooks/          # usePlayer / useProgression / useQuests / useGameSettings
├── routes/         # ตัวคุ้มกันเส้นทางที่ต้องมีตัวละครก่อน
├── data/           # ข้อมูลเกม: โลก, ด่าน, ภารกิจ, NPC, โจทย์, ทักษะ, รางวัล
├── types/          # นิยาม TypeScript
├── render3d/       # แกนกลางการวาดสามมิติ ใช้ร่วมกันทั้งเขาวงกตและฟาร์ม
├── safezone/       # Safe Zone Guardians: เขาวงกต ตรรกะการเดิน โจทย์ ป.4 และการวาดฉาก
├── farm/           # โดมสีเขียว: ฟาร์ม สัตว์ ทรัพยากรโดม สมุดบัญชี และรหัสฟาร์ม
├── geometry/       # ห้องเรขาคณิต: คณิตศาสตร์ของรูป กระดานวาด และอุปกรณ์วงเวียน/ครึ่งวงกลม
├── services/       # storage / rewardService / questService / eventBus / audioService
└── utils/          # experience, stageSystem, statistics, questionGenerator
```

### เพิ่มด่านใหม่

แก้ไฟล์ `src/data/stages.ts` ไฟล์เดียว แล้วเกมจะแสดงด่านใหม่บนแผนที่ให้อัตโนมัติ
พร้อมระบบปลดล็อก ดาว รางวัล และการนับความคืบหน้าของโลก

หลักการที่ยึดไว้

- **ข้อมูลเกมอยู่ใน `data/` เท่านั้น** ไม่ hard-code ไว้ใน component
- **ตรรกะอยู่ใน `utils/` และ `services/`** component ทำหน้าที่แสดงผลเป็นหลัก
- TypeScript แบบ strict ไม่ใช้ `any`
