# 🧭 Math Adventure

เกมผจญภัยคณิตศาสตร์สำหรับนักเรียนชั้นประถมศึกษาปีที่ 4 – 6

แนวคิดหลักของเกม: **Explore → Quest → Math Challenge → Reward → Level Up → Unlock**

> สถานะปัจจุบัน: **Part 3** — ระบบโลก ด่าน ภารกิจ และการปลดล็อก ข้อมูลทั้งหมดเก็บในเครื่องผู้เล่นด้วย `localStorage` ยังไม่ต่อ Backend

---

## เริ่มเล่น

ต้องมี Node.js เวอร์ชัน 18 ขึ้นไป

```bash
npm install
npm run dev
```

จากนั้นเปิดเบราว์เซอร์ไปที่ URL ที่แสดงบนหน้าจอ (ปกติคือ `http://localhost:5173`)

คำสั่งอื่น ๆ

```bash
npm run build      # ตรวจ TypeScript แล้ว build ไฟล์สำหรับขึ้นเซิร์ฟเวอร์จริง
npm run preview    # ลองเปิดไฟล์ที่ build แล้ว
npm run typecheck  # ตรวจ type อย่างเดียว
```

## เส้นทางการเล่น

```
เปิดเกม → สร้างตัวละคร (เลือกชื่อ + อาชีพ 1 ใน 6)
        → เมนูหลัก → แผนที่โลก → World 1 → แผนที่ด่าน
        → เลือกด่าน → NPC เล่าภารกิจ → ตอบโจทย์คณิตศาสตร์
        → หน้าผลลัพธ์: ดาว + รางวัล + ปลดล็อกด่านถัดไป
        → สะสมดาวจนพิชิตโลก → ปลดล็อกโลกใหม่
        → (รีเฟรชแล้วความคืบหน้าทั้งหมดยังอยู่)
```

## ระบบที่ทำงานจริงแล้ว

| ระบบ | รายละเอียด |
| --- | --- |
| ตัวละคร | ชื่อ + อาชีพ 6 แบบ, เริ่มที่ Lv.1 / 0 EXP / 100 เหรียญ / HP 100 |
| แผนที่โลก | 6 โลก เชื่อมเป็นเส้นทาง World 1 เปิด ส่วน 2–6 ล็อกพร้อมบอกวิธีปลดล็อก |
| ด่าน | World 1 มี 10 ด่าน แบ่งเป็น 3 ภูมิภาค ปลดล็อกไล่ตามลำดับ ด่านที่ 10 เป็นมินิบอส |
| ดาว / Mastery | ผ่าน 60–69% = ⭐, 70–89% = ⭐⭐, 90–100% = ⭐⭐⭐ (ครบ 3 ดาว = MASTERED) |
| ภารกิจ | ภารกิจหลัก 3 · เสริม 6 · ประจำวัน 2 (รีเซ็ตทุกวัน) พร้อมระบบกดรับรางวัล |
| NPC | ตัวละครผู้ช่วย 5 ตัว เล่าภารกิจก่อนเริ่มด่าน |
| โจทย์ | คลังโจทย์ 28 ข้อ (บวก ลบ คูณ หาร) + ตัวสร้างโจทย์สำรองเมื่อคลังไม่พอ |
| รางวัล | ตอบถูก +10 EXP / +5 เหรียญ, จบด่านได้โบนัสตาม `firstClearReward` / `replayReward` |
| เลเวล | Lv.1 = 100 EXP, Lv.2 = 150, Lv.3 = 225, Lv.4 = 325, Lv.5 = 450 |
| สถิติ | ความแม่นยำรวม, streak, และสถิติรายทักษะ 9 ด้าน พร้อมดาวประเมินระดับ |
| บันทึกข้อมูล | `localStorage` เวอร์ชัน 3 พร้อม migration จาก Part 1 และ Part 2 อัตโนมัติ |
| ความสำเร็จ | 12 รายการ คำนวณจากข้อมูลผู้เล่นจริง |
| ตั้งค่า | เปิด/ปิดเสียง ดนตรี เอฟเฟกต์การเคลื่อนไหว และลบข้อมูลเริ่มใหม่ |

## แนวทางการออกแบบสำหรับเด็ก

- ปุ่มหลักสูงอย่างน้อย 48–60px แตะง่ายบนมือถือ
- ใช้ภาษาไทยทั้งหมด ไม่ใช้ศัพท์เทคนิค
- ตอบผิดเสียพลังชีวิตเล็กน้อยแล้วได้คืนตอนจบด่าน ลองใหม่ได้เสมอ พร้อมคำใบ้
- บอกถูก/ผิดด้วย **สี + ไอคอน + ข้อความ** ไม่ใช้สีอย่างเดียว
- รองรับการใช้คีย์บอร์ด และมีกรอบโฟกัสที่มองเห็นชัด
- มีตัวเลือกปิดเอฟเฟกต์การเคลื่อนไหว และเคารพ `prefers-reduced-motion` ของระบบ
- ทักษะที่ยังไม่เคยฝึกแสดง "ยังไม่มีข้อมูล" แทนดาว 0 ดวง และใช้ข้อความชวนฝึกต่อเสมอ

## โครงสร้างโปรเจกต์

```
src/
├── components/     # ส่วนประกอบ UI ที่ใช้ซ้ำ (ปุ่ม, แถบ EXP, การ์ดด่าน, ดาว, โจทย์ ฯลฯ)
├── pages/          # หน้าจอแต่ละหน้าของเกม
├── context/        # GameContext เชื่อมทุกระบบเข้าด้วยกัน
├── hooks/          # usePlayer / useProgression / useQuests / useGameSettings
├── routes/         # ตัวคุ้มกันเส้นทางที่ต้องมีตัวละครก่อน
├── data/           # ข้อมูลเกม: โลก, ด่าน, ภารกิจ, NPC, โจทย์, ทักษะ, รางวัล
├── types/          # นิยาม TypeScript
├── services/       # storage / rewardService / questService / eventBus / audioService
└── utils/          # experience, stageSystem, statistics, questionGenerator
```

### เพิ่มด่านใหม่

แก้ไฟล์ `src/data/stages.ts` ไฟล์เดียว แล้วเกมจะแสดงด่านใหม่บนแผนที่ให้อัตโนมัติ
พร้อมระบบปลดล็อก ดาว รางวัล และการนับความคืบหน้าของโลก

หลักการที่ยึดไว้

- **ข้อมูลเกมอยู่ใน `data/` เท่านั้น** ไม่ hard-code ไว้ใน component
- **ตรรกะอยู่ใน `utils/` และ `services/`** component ทำหน้าที่แสดงผลเป็นหลัก
- TypeScript แบบ strict ไม่ใช้ `any`
