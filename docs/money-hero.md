# MONEY HERO – ปฏิบัติการเมืองเงินทอง

เกมการเรียนรู้คณิตศาสตร์ ป.3 เรื่อง **เงิน** แนว Educational Adventure + Simulation + Mini Games
เปิดที่ `money-hero.html` (แยกจากเกมผจญภัยเดิมใน `index.html` แต่อยู่ในโปรเจกต์เดียวกัน)

> สถานะ: เล่นได้ครบ **ด่าน 0–12** ในเมืองแบบมองจากด้านบน · แบบทดสอบก่อน/หลังเรียนพร้อมกราฟเทียบ
> · ตราสัญลักษณ์ · โปรไฟล์ · สถิติทักษะ · ฝึกข้อที่เคยผิด · แผงคุณครู + ดาวน์โหลด CSV
> · มินิเกม **AR ล่าเหรียญ** (ใช้กล้อง หรือเล่นบนฉากการ์ตูนก็ได้)

## เล่น

```bash
npm install
npm run dev
# เปิด http://localhost:5173/money-hero.html
```

build: `npm run build` → ได้ `dist/money-hero.html`

เผยแพร่: push ขึ้น branch หลักของ repo แล้ว GitHub Actions (`deploy.yml`) จะขึ้น GitHub Pages ให้เอง
เปิดได้ที่ `https://<ชื่อผู้ใช้>.github.io/Math-Games/money-hero.html`
เป็น Progressive Web App ติดตั้งลงแท็บเล็ต/มือถือได้ และเปิดได้แม้ออฟไลน์หลังเปิดครั้งแรก

## วิธีเล่น

- **แผนที่เมือง**: ลูกศร / WASD เดินได้ทุกทิศ · Enter เข้าอาคารหรือคุยกับเพื่อน · เก็บเหรียญริมถนน
  บนแท็บเล็ต/มือถือใช้จอยสติกบนจอ หรือแตะอาคารให้ฮีโร่เดินตามถนนไปเอง · มีปุ่ม "ดูรายการด่าน" สำหรับคนที่ไม่อยากเดิน
- **แบบทดสอบก่อนเรียน** (18 ข้อ) ทำได้ตั้งแต่เริ่ม · **หลังเรียน** (20 ข้อ) เปิดเมื่อผ่านด่าน 12
  ระหว่างทำไม่บอกถูกผิด ไม่มีตัวช่วย จบแล้วเห็นคะแนนรายทักษะ และกราฟก่อน → หลังเรียน
- **เมนูใต้แผนที่**: 🏆 ตรา · 👤 โปรไฟล์ (เปลี่ยนชื่อ/ตัวละครได้) · 📊 สถิติทักษะ · 🔁 ฝึกข้อที่เคยผิด
- **🧮 โต๊ะนับเงิน** (`#/sandbox`): เล่นอิสระ วางเงินบนโต๊ะแล้วเห็นยอดรวม (บาท–สตางค์ และแบบจุด) แยกนับตามชนิด
  ปุ่ม "แลกให้น้อยชิ้นที่สุด" · เปิดได้จากเมนูใต้แผนที่ และจากแผงคุณครูสำหรับสาธิตหน้าห้อง
- **🎵 เพลงประกอบ**: เพลงเบา ๆ สังเคราะห์สด (ไม่มีไฟล์เสียง) เล่นเฉพาะหน้าแรกและแผนที่ ตอนทำโจทย์เงียบ
  ปิดได้ที่ปุ่ม 🎵 หน้าแรก หรือหน้าตั้งค่า (ปิดเสียงทั้งหมดก็ปิดเพลงด้วย)
- **❗ ภารกิจจากเพื่อนในเมือง**: เพื่อนที่มีเครื่องหมาย ❗ บนหัวมีภารกิจให้ (วันละครั้งต่อเพื่อน)
  กระต่ายนับเงิน · จิ้งจอกเปรียบเทียบ · ลุงหมีคิดเงินทอน · นกฮูกรายรับรายจ่าย · แตะเพื่อนหรือเดินไปคุยก็ได้
- **🌞 ภารกิจประจำวัน** (`#/daily`): วันละ 5 ข้อจากด่านที่ผ่านแล้ว ทำติดกันได้สตรีค 🔥 และตราประทับ ⭐ บนปฏิทิน 7 วัน
  เปิดซ้ำในวันเดียวกันได้โจทย์ชุดเดิม · ติดกัน 3 วันได้ตรา "ขยันทุกวัน"
- **🛍️ ร้านของฮีโร่** (`#/shop`): ใช้เหรียญที่สะสมซื้อหมวก แว่น และสัตว์เลี้ยง (ลูกเจี๊ยบ ลูกแมว ลูกหมา หมูออมสิน มังกรน้อย ยูนิคอร์น)
  ลุงหมีคิดเงินให้ดูทุกครั้ง "มี … จ่าย … เหลือ …" ซื้อไม่ได้ก็บอกว่าขาดอีกกี่เหรียญ
  ของที่สวมแสดงบนตัวละครทุกหน้า และสัตว์เลี้ยงเดินตามฮีโร่บนแผนที่
- **🌱 กาดรักษ์โลก** (`#/eco` เมนูบนแผนที่): เล่นครบวงจรวันละรอบ
  เลือกสินค้า (กระถาง / กระปุกใส่ดินสอ / สมุดรีไซเคิล / กระปุกออมสิน) → **คัดแยกขยะ** ลงถังพลาสติก/โลหะ/กระดาษ
  → **ขายขยะ** ให้ธนาคารขยะ (จำนวน × ราคา แล้วรวม) → **ซื้ออุปกรณ์** (รวมราคา และเงินเหลือ) → ทำสินค้า
  → **ตั้งราคา** (ถูก = ขายได้หลายคน แพง = ลูกค้าบางคนไม่ซื้อ) → **ขายและทอนเงิน** → **กำไร = รายได้ − ต้นทุน**
  → **แบ่งกำไร** ลงทุนรอบใหม่ (เป็นทุนวันถัดไป) / เก็บออม (เข้ากระปุกเป็นเหรียญ) / บริจาคกองทุนต้นไม้ / ซื้อของให้เพื่อน (รวมต้องเท่ากำไรพอดี)
  - ยอดขายสะสมทำให้ต้นไม้ของผู้เล่นโต ปลดล็อกที่ 100 / 200 / 300 บาท · ได้ตรา "พ่อค้าแม่ค้ารักษ์โลก" และ "สวนรักษ์โลก"
  - **ในเมือง**: ใต้แม่น้ำมี "ถนนรักษ์โลก" แยกจากเชิงสะพาน มีแผงกาดรักษ์โลก (แตะแล้วฮีโร่เดินไปเอง → เปิดร้าน)
    และ **สวนของฮีโร่** ต้นไม้โตตามยอดขายสะสม มีดอกไม้เพิ่มตามเงินที่บริจาคกองทุนต้นไม้
  - **ขยะรายวันบนถนน** วันละ 6 ชิ้น (ทุกเครื่องเห็นเหมือนกันในวันเดียวกัน) เดินผ่านเพื่อเก็บใส่ถุง (สูงสุด 12 ชิ้น)
    ขยะในถุงไปเพิ่มในกองตอนเล่นกาด ขายได้เงินเพิ่ม
  - โจทย์ทุกข้อใช้ตัวเดินโจทย์เดิม (มีตัวช่วย วิธีคิด) และนับลงสถิติทักษะ คูณ–หาร / บวก–ลบ / โจทย์ปัญหา
  - ตรรกะอยู่ที่ `engine/eco.ts` ชุดทดสอบสุ่มเล่น 1,500 วัน
- **💵 ร้านทอนไว** (`#/change` เมนูบนแผนที่): ลูกค้ามาซื้อของที่แผงกาด จ่ายแบงก์มา แตะเหรียญ/ธนบัตรในลิ้นชักให้ทอนพอดี
  ทอนถูกติดกันได้คอมโบ 🔥 และโจทย์ยากขึ้น (ทอนด้วยเหรียญบาท → ธนบัตร 20/50 → ซื้อ 2 ชิ้นหรือราคามีสตางค์)
  มีโหมดฝึก 8 ลูกค้า (ไม่จับเวลา) และท้าเวลา 60 วินาที (เก็บสถิติ ทอนถูก 8 คนได้ตรา "ทอนไวทันใจ") · ตรรกะ `engine/changeGame.ts`
- **🐷 กระปุกออมสิน** (`#/bank` หรือแตะชิปเหรียญ 🪙 บนแถบบน): กระปุกหมูแตะแล้วดุ๊กดิก
  บอกว่าถ้าเหรียญเป็นเงินบาทจะแลกเป็นธนบัตร/เหรียญได้น้อยชิ้นที่สุดอย่างไร
  - ตั้งเป้าหมายการออมเป็นของในร้าน แถบบอก "ขาดอีก … เหรียญ" (ราคา − มีอยู่) ออมครบแล้วซื้อได้ตรา "นักออมตัวจริง"
  - **สมุดบัญชีรายรับรายจ่าย** ของเด็กเอง: ทุกเหรียญที่ได้ (ตอบถูก ผ่านด่าน ภารกิจ ล่าเหรียญ) และจ่าย (ซื้อของ) ลงสมุดอัตโนมัติ
    มีวันที่ รายการ รายรับ รายจ่าย คงเหลือ และบรรทัดยอดยกมา · ยอดยกมา + รายรับ − รายจ่าย = คงเหลือ เสมอ
  - นกฮูกตั้งคำถามจากสมุดของเด็กเอง "มีอยู่ … แล้วได้รับ/จ่ายไป … จะเหลือเท่าไร"
  - ตรรกะอยู่ที่ `engine/ledger.ts` (ทุกจุดที่เหรียญเปลี่ยนต้องเรียก `earn()` เพื่อให้ลงสมุด)
- **📷 ล่าเหรียญ AR** (`#/ar`): เปิดกล้องหลังของแท็บเล็ต/มือถือ เหรียญและธนบัตรลอยอยู่บนภาพจริงรอบตัว
  แตะเก็บให้ได้จำนวนเงินพอดีตามโจทย์ 5 รอบ (เหรียญบาท → ธนบัตร → สตางค์ → รวมทุกอย่าง)
  ไม่มีกล้องหรือไม่อนุญาตก็เล่นบนฉากการ์ตูนได้ · ภาพจากกล้องไม่ถูกบันทึกหรือส่งไปไหน
  - **🤏 จีบนิ้วเลือก**: เปิดกล้อง (กล้องหน้าเหมาะที่สุด) ชูมือให้กล้องเห็น จะมีวงแหวนตามนิ้ว
    จีบนิ้วโป้งกับนิ้วชี้ตรงเหรียญ = เก็บ (ใช้กับปุ่มตรวจ/คืน/รอบต่อไปได้ด้วย) วงแหวนหดตามระยะจีบให้เห็นว่าใกล้เลือกแล้ว
  - ตรวจจับมือด้วย MediaPipe Hand Landmarker โหลดจาก CDN ตอนเปิดกล้องครั้งแรก ประมวลผลบนเครื่องเท่านั้น
    โหลดไม่ได้ (ออฟไลน์/เครื่องเก่า) ก็ยังแตะจอเล่นได้ · ปุ่ม 🤏 บนแถบบนเปิด/ปิดการจีบนิ้วได้
  - ตรรกะจีบนิ้วอยู่ที่ `engine/pinch.ts` (ระยะโป้ง–ชี้ ÷ ขนาดฝ่ามือ มีช่วงกันสั่น) ตัวโหลดอยู่ที่ `utils/handTracker.ts`
  ตรรกะอยู่ที่ `engine/coinHunt.ts` ทุกรอบสร้างจากชุดคำตอบก่อน จึงเก็บได้พอดีเสมอ
- **ฝึกข้อที่เคยผิด**: โจทย์แบบเดียวกับที่เคยพลาดแต่ตัวเลขใหม่ ตอบถูกแล้วข้อนั้นหายจากรายการ
- **ทุกด่านมี 4 ขั้น**: LEARN (บทเรียนสั้น ๆ + เงินจำลอง) → PRACTICE → MISSION → BOSS
- **🧰 ถนนดาว** (`#/stars`, เมนู "ถนนดาว" บนแผนที่): ดาวด่านหลัก (39) + ดาวด่านย่อย (78) = 117 ดาว
  มีหีบสมบัติ 10 หีบที่ 3, 8, 15, 24, 36, 50, 66, 84, 100, 117 ดาว ได้เหรียญ (ลงสมุดบัญชี) และบางหีบมีของแต่งตัว/สัตว์เลี้ยงฟรี
  (มีของชิ้นนั้นแล้วได้เหรียญครึ่งราคาแทน) · หน้าจบด่านบอกว่ามีหีบรอเปิดหรืออีกกี่ดาว · ตรา 🧰 นักล่าสมบัติ: เปิดครบ 5 หีบ
  ตรรกะอยู่ที่ `engine/starRoad.ts` ภาพหีบ `components/ChestArt.tsx`
- **🗣️ เสียงพูดภาษาไทย** (`utils/speech.ts`): เลือกเสียงไทยของเครื่องเสมอ (รอรายชื่อเสียงโหลดก่อน ไม่ให้เสียงอังกฤษอ่านแทน)
  ตัดอีโมจิ อ่านเครื่องหมายคำนวณ (คูณ หาร บวก ลบ เท่ากับ) และคำอังกฤษในเกมเป็นคำไทย · ตัวละครพูดชม/ให้กำลังใจหลังตอบทุกข้อ
  บอสพูดตอนเริ่มและตอนหมดแรง · เพื่อนเล่าภารกิจและชมตอนภารกิจครบ · โค้ชอธิบายกติกาลานฝึก
  ตัวเลือก "อ่านโจทย์ให้ฟังเองทุกข้อ" (ปิดไว้ก่อน) สำหรับน้องที่ยังอ่านช้า
  ชื่อขั้นบนหน้าจอเป็นภาษาไทย: เรียนรู้ · ฝึกซ้อม · ภารกิจ · สู้บอส และหน้าผลลัพธ์ "ผ่านด่านแล้ว!"
  หน้าตั้งค่าบอกว่าเครื่องมีเสียงไทยหรือยัง พร้อมวิธีเพิ่มเสียงไทยใน Android / iPad / Windows และปุ่มทดลองฟังเสียง
- **🎮 ด่านย่อย X-1 · X-2 · X-3** (ทุกด่าน 0–12): X-1 คือด่านผจญภัยเดิม
  X-2 ฝึกเก่ง 🎈 (โจทย์ระดับกลาง ≥ 6 ข้อ ฉากยิงลูกโป่ง) เปิดเมื่อผ่าน X-1 · X-3 ท้าทาย 🔥 (โจทย์ระดับยาก ≥ 8 ข้อ สู้บอสร่างโหด) เปิดเมื่อผ่าน X-2
  โจทย์วนชนิดโจทย์ทั้งหมดของด่านนั้น · ผ่านเมื่อถูก (ภายใน 2 ครั้ง) ≥ 60% · ดาวคิดจากข้อที่ถูกตั้งแต่ครั้งแรก · เก็บดาวที่ดีที่สุด เล่นซ้ำได้รางวัลครึ่งหนึ่ง
  ไม่บังคับ ด่านถัดไปบนแผนที่ยังเปิดเมื่อผ่าน X-1 · เข้าได้จากหน้าผลลัพธ์และแผงด่านบนแผนที่ (`#/level/:id/stage/:n`)
  ตรรกะอยู่ที่ `engine/stages.ts` โจทย์ `buildStage` ใน `generators/index.ts` · ตรา 🔥 นักล่าความท้าทาย: ผ่าน X-3 ครบ 3 ด่าน
- **🎈 ลานฝึกยิงลูกโป่ง** (ขั้น PRACTICE ทุกด่าน): หนึ่งข้อ = ลูกโป่งหนึ่งลูก โค้ชประจำด่านเชียร์
  ถูกตั้งแต่ครั้งแรก ลูกโป่งแตกได้ ⭐ (ต่อกันเป็นคอมโบ 🔥) · ถูกครั้งที่ 2 ได้ 👍 · ผิดครบ 2 ครั้งลูกโป่งลอยหนี (ไม่ลงโทษ)
  ข้อมูลอยู่ที่ `data/practice.ts` ภาพอยู่ที่ `components/PracticeRange.tsx`
- **⭐ เกณฑ์ดาวบนหน้าผลลัพธ์**: แถบแสดงสัดส่วนข้อที่ถูกตั้งแต่ครั้งแรกเทียบเส้น ⭐⭐ (70%) และ ⭐⭐⭐ (90%)
  พร้อมบอกว่าต้องถูกตั้งแต่ครั้งแรกอีกกี่ข้อจึงได้ดาวเพิ่ม (`nextStar` ใน `engine/scoring.ts`)
- **🎯 ฉากภารกิจ** (ขั้น MISSION ด่าน 0–11): เพื่อนในเมืองเล่าภารกิจตามชื่อด่าน (เช่น ตลาดเช้านับเงิน แคชเชียร์ซูเปอร์มาร์เก็ต สายพานโรงงานเงิน เติมสมุดบัญชี)

  ข้อมูลฉากอยู่ที่ `data/missions.ts` แถบภารกิจอยู่ที่ `components/MissionTrack.tsx` (ด่าน 12 ใช้ภารกิจหนึ่งวันในเมืองเหมือนเดิม)

## โครงสร้างโค้ด

```
src/moneyHero/
  engine/      ชนิดข้อมูล ตรวจคำตอบ คะแนน ความก้าวหน้า localStorage รายงาน CSV
  generators/  ตัวสร้างโจทย์ทุกด่าน (แยกจากหน้าจอ) + แผนคำถามของแต่ละด่าน + แบบทดสอบ
  data/        เงิน 11 ชนิด ตัวละคร สินค้า ด่านและบทเรียน ตรา
  utils/       คณิตศาสตร์เงิน (สตางค์จำนวนเต็ม) ตัวสุ่ม เสียง อ่านออกเสียง
  hooks/       สถานะเกม รูปภาพ ลากวาง
  components/  ภาพเงิน/ตัวละคร ภาพประกอบ ช่องตอบแต่ละแบบ ตัวเดินโจทย์
  pages/       หน้าจอทั้งหมด
  styles/      money.css
```

**เงินทุกจำนวนเก็บเป็นสตางค์จำนวนเต็ม** เช่น 25.50 บาท = `2550` ไม่ใช้ทศนิยมของ JavaScript

## เพิ่มคำถามใหม่

1. เขียนฟังก์ชันใน `src/moneyHero/generators/` ที่คืน `Question` (ดูแบบใน `types.ts`)
   ต้องมี `hint` ครบ 3 ระดับ และ `explain` วิธีคิดทีละขั้น
2. ลงทะเบียนชื่อใน `GENERATORS` ของ `generators/index.ts`
3. ใส่ชื่อใน `LEVEL_PLANS` ของด่านที่ต้องการ พร้อมระดับ 1–3
4. รัน `node tests/moneyHero.test.mjs /tmp/logic` ชุดทดสอบจะสุ่มโจทย์ใหม่หลายร้อยข้อ
   ตรวจว่าทุกข้อมีคำตอบที่ถูก ตัวเลือกไม่ซ้ำ และไม่มีข้อที่กำกวม
