# ชุดทดสอบ Math Adventure

ทดสอบเฉพาะตรรกะล้วน (ไม่แตะ React) จึงรันได้โดยไม่ต้องติดตั้ง dependency
ใช้ `tsc` คอมไพล์เป็น CommonJS แล้วรันด้วย Node

> **หมายเหตุสำคัญ:** เครื่องที่พัฒนาอยู่นี้เข้า npm registry ไม่ได้ (403)
> จึงยังรัน `npm run build` และทดสอบหน้าจอ React ไม่ได้
> ชุดทดสอบนี้ครอบคลุมเฉพาะชั้นตรรกะและคณิตศาสตร์
> หน้าจอของเกมอวกาศตรวจด้วยชุดเล่นจริงในเบราว์เซอร์ ซึ่งรันบน GitHub Actions (ดูหัวข้อด้านล่าง)

## รันทั้งหมด

```bash
# คอมไพล์ตรรกะเกม แล้วรันชุดทดสอบทั้งสาม
npx tsc -p tsconfig.tests.json --outDir /tmp/logic
node tests/progression.test.mjs /tmp/logic     # ระบบความก้าวหน้า Part 1–3
node tests/questionEngine.test.mjs /tmp/logic  # Question Engine และ Math Engine Part 4
node tests/stageQuestions.test.mjs /tmp/logic  # การต่อด่านเข้ากับ Question Engine
node tests/safezone.test.mjs /tmp/logic        # Safe Zone Guardians เขาวงกตสามมิติและภารกิจ ป.4
node tests/solar.test.mjs /tmp/logic           # ยานสำรวจระบบสุริยะ ข้อมูลดาว ใบ้พิกัด โจทย์ ทริป และการวาดฉาก
node tests/planetQuest.test.mjs /tmp/logic     # ภารกิจแปดดาว เนื้อหาวิทยาศาสตร์ ป.6 เกมแปดแบบ บทเรียน และอุปราคา
node tests/farm.test.mjs /tmp/logic            # โดมสีเขียว ฟาร์ม สมุดบัญชี รหัสฟาร์ม และสมดุลเกม
node tests/timeAdventure.test.mjs /tmp/logic   # ผจญภัยเมืองแห่งเวลา การ์ดเวลา ป.2 และเครื่องยนต์เกม
node tests/timePractice.test.mjs /tmp/logic    # โหมดฝึกอ่านนาฬิกา โจทย์สุ่มหลายหมื่นข้อ
node tests/teacher.test.mjs /tmp/logic         # แผงคุณครู ตัวชี้วัด รหัสผลการเรียน และสรุปทั้งห้อง
node tests/survivor.test.mjs /tmp/logic        # สนามรบตัวเลข เครื่องยนต์และองค์ประกอบของสนาม
node tests/art.test.mjs /tmp/logic             # ภาพตัวละคร มอนสเตอร์ ฉาก และแผนที่ด่าน
node tests/geometry.test.mjs /tmp/logic         # ห้องเรขาคณิต วงเวียน ครึ่งวงกลม และรูปหลายเหลี่ยม

# เกมการ์ด Divisor Duel คอมไพล์แยก เพราะโหลดโมดูลด้วยเส้นทางคนละแบบ
npx tsc -p tsconfig.duel.json --outDir /tmp/duel
node src/divisorDuel/web/test.mjs /tmp/duel
```

ทุกชุดรันบน GitHub Actions อัตโนมัติทุกครั้งที่ push ดูผลได้ที่แท็บ Actions

## เล่นจริงในเบราว์เซอร์ (`e2e/space.e2e.mjs`)

ชุดข้างบนไม่ได้เปิดหน้าจอเลย ชุดนี้เปิดเว็บที่ build แล้วใน Chromium
สร้างตัวละคร แล้วให้บอตกดเล่นเกมอวกาศสองเกมจนจบจริง

- **ภารกิจแปดดาว** บินเที่ยวในโหมดสำรวจ เลื่อนตาชั่งกับอายุ เปิดห้องทดลองอุปราคา ·
  อ่านบทเรียนครบหกบทพร้อมตอบคำถามท้ายบท · เล่นด่านทั้งแปดดาวจนจบ แล้วรับใบประกาศ ·
  ตรวจว่าดาวที่ยังไม่เคยไปหลับอยู่ ไปถึงแล้วตื่นมาทัก และดาวเจ้าบ้านทัก เชียร์ และบอกลาครบทุกดาว
- **ยานสำรวจระบบสุริยะ** ทริปสั้นหนึ่งทริปจนถึงหน้าสรุป
- เปิดทั้งสองเกมบนจอขนาดมือถือ แล้วตรวจว่าไม่มีอะไรล้นจอจนต้องเลื่อนซ้ายขวา

บอตอ่านเฉลยจากไฟล์เนื้อหาตัวจริง จึงตอบถูกทุกข้อ และตรวจได้ว่าเล่นถูกหมดแล้วได้สามดาวจริง
(ยกเว้นไพ่จับคู่ที่ต้องเปิดดูก่อน) ถ้าหน้าเว็บมี error ปุ่มที่ควรมีไม่ขึ้น หรือได้ดาวไม่ครบ ชุดนี้จะตก

```bash
npm run build
npx tsc -p tsconfig.tests.json --outDir /tmp/logic
node tests/e2e/space.e2e.mjs dist /tmp/logic   # ต้องมี playwright กับ Chromium ในเครื่อง
```

ภาพหน้าจอทุกขั้นถูกเก็บไว้ที่ `test-results/`
บน GitHub Actions ดาวน์โหลดได้จากหน้าสรุปของการรัน ชื่อ `space-game-screenshots`
