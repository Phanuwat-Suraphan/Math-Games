# รูปตัวละคร MONEY HERO

วางรูป PNG (พื้นหลังโปร่งใส) ไว้ในโฟลเดอร์นี้ด้วยชื่อต่อไปนี้ เกมจะใช้รูปทันทีโดยไม่ต้องแก้โค้ด
ถ้ายังไม่มีไฟล์ เกมจะใช้ภาพวาด SVG ของตัวละครนั้นแทน (`src/moneyHero/components/CharacterSvg.tsx`)

| ไฟล์ | ตัวละคร |
| --- | --- |
| `hero.png` | MONEY HERO (ตัวเอกที่เดินบนแผนที่) |
| `rabbit.png` | 🐰 กระต่ายนักนับเงิน |
| `fox.png` | 🦊 จิ้งจอกนักคิด |
| `bear.png` | 🐻 หมีเจ้าของร้าน |
| `owl.png` | 🦉 นกฮูกนักบัญชี |
